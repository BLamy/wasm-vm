01 / THE MACHINE

Hardware in software.
Linux above it.

Browser APIs sit below the guest. Linux sees a CPU, memory, interrupts, and devices through the virtual platform.

01

Execute real RISC-V binaries

Run a bare-metal ELF or boot a kernel. RV64GC, privileged state, precise traps, and virtual memory form the architectural boundary.

02

Keep a writable disk

Chunked disk images fetch the blocks the guest needs. An IndexedDB copy-on-write overlay keeps local changes across reloads.

The workbench offers serial and display views with guest keyboard and pointer input. Guest GPU offload remains partial; default production acceleration is disabled.
