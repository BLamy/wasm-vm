North star

One URL, one user-owned computer, inspectable work.

A user boots Linux, unlocks an encrypted overlay, receives verified blocks from the best available source, and can publish a reproducible optimization task to a network of builders and critics.

Principles

What will not change.

Verifier before token

Settlement starts with deterministic acceptance. A coin is optional infrastructure, not a correctness mechanism.

Private by default

User overlays stay local until a user explicitly publishes an encrypted generation.

AI proposes, code decides

AI can draft a task, test suite, or critic report. Only hashed executable policy can settle it.

Scope language: distributed delivery and encrypted storage come first. We will not call this a fully distributed operating system until processes and coordinated services actually span browser nodes.
