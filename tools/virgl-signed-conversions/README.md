# Private signed conversion evidence

`make verify-E6-T12g6e` records the S/high I2F/F2I boundary. It builds the owned
C parser/word helpers with ASan, UBSan and LLVM coverage, compares complete
native/Wasm bridge results, and obtains the unmodified GLSL and operand types
from pinned Mesa 24.2.8. Existing captured admissions and promoted bounds,
hexadecimal and signed-selection guards remain unchanged.

The physical headed WebGL2 run uses independent integer/rational source
equations, finite carriers revealing every result bit, and 32 RGBA8 bit planes.
It records endpoints, all exponents, tie parity, fractional truncation, signed
zeros/subnormals, modifiers, masks, aliases, joins, input attributes and changing
constant banks. Three fixed seeds vary values, positions and async schedules.
The receipt recomputes every physical byte using Python binary32 pack/unpack
and truncation, independent of the C and JavaScript conversion equations.

I2F is total over all signed32 bit patterns and selects nearest-even. F2I only
accepts finite encodings below positive2^31 or at most negative2^31. Unknown
direct, unmodified constant operands require sorted post-swizzle component
range obligations. Static bit proofs can admit computed or modified sources;
unproven inputs, computed values, indirect banks and modified dynamic banks
remain rejected. Both GLSL helpers operate on unsigned words, so neither
executes an undefined float-to-int conversion. Integer results inherit no
numeric or output authority; explicit I2F produces normal/zero float words.

Conversion metadata wraps every preexisting contract through a bounded base
profile. The consumer retains prior finite-prefix, loop, radial, raster and
precise-arithmetic obligations. Real resource/decoder/state consumers prove
both stages in synchronous and async indexed draws, complete declared prefixes
despite reflection pruning, caller ownership, restoration, no effects from
unsafe banks, immutable plans across index waits and zero final budgets.

Mesa stores TEMP values as float, so upstream raw comparisons are limited to
normal/zero source and result encodings where necessary. Owned word/pixel
checks have no such restriction. The complete captured compositors and
production negotiation remain gated; this suite does not boot a guest or
measure MIPS/FPS.

Three deliberate faults disable tie parity, negative truncation and the real
consumer component range check. Exact word predictions catch the first two;
an independent native-call intercept stops the third before its unsafe GPU
effect. Generated fault sources are authenticated in the recording.

Freeze tracked sources, run acceptance once, then
`python3 tools/virgl-signed-conversions/cold.py --output <cold-dir>` for the
single pristine scrubbed clone. Seal with `seal.py --hot <hot-dir> --cold
<cold-dir> --output evidence/virgl-signed-conversions/worker`. The archive,
index and source digests are the worker claim. A fresh critic must independently
attack the recording and audit changed-hunk coverage before verification.
