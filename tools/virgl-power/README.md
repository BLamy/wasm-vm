This private compiler leaf admits TGSI POW only when static post-modifier
word facts prove a nonnegative normal-or-zero base and finite normal-or-zero
exponent. Zero-capable bases require a strictly positive exponent throughout
the possible word cube. Positive bases require a clear sign. Integer exponent
bounds enclose log2(base), and integer significand/scale comparisons require
max(abs(log2 bounds))*max(abs(exponent)) <=120. This margin keeps nonzero
mathematical results inside [2^-120,2^120]. Outputs gain no static range,
exact-word or F2I authority. Both scalar post-swizzle operands are captured
before masked/aliased publication; zero bypasses native pow and returns +0.

`make verify-E6-T12g6j2` records native/Wasm singles and pairs, pinned FLOAT/REPL
tokens and original converter GLSL, whole predecessor results and contracts,
inherited guards, owned metadata and banks, real synchronous/asynchronous
restoration,72 isolated original literal-exponent statements, three physical
seeds and base/exponent/broadcast source faults. The26 original computed or
uniform exponent sites remain unproven. `cold.py` uses a pristine exact-head
clone and scrubbed environment. `seal.py` preserves both actual sanitizer
binaries alongside their original profiles.

`reference.py` starts from exact rational binary32 inputs. Decimal ln/exp are
correctly rounded to nearest-even; one unit of the last precision place bounds
each operation outward, while multiplication rounds down/up. Separate160/220
significant-digit enclosures must nest. Proven identities, integer powers and
integer powers of two use exact fractions. Acceptance requires relative error
<=2^-14 for every real value in the enclosure, with exact owned +0 for zero.
This is a measured physical-host budget. ESSL3.00 section4.5.1 inherits pow
precision from an expression with apparently swapped arguments; this boundary
does not interpret that as an unambiguous portable accuracy guarantee.

Its unmodified sources execute under separate componentwise predictions.

equations. Concrete nonbroadcast deviations are recorded. Two finite feedback
carriers preserve all32 bits; each RGBA8 pixel exposes all four bytes of a
single evaluation. Predecessor unsupported-POW spelling fixtures migrate to
