This private S boundary accepts the original explicit fragment header:

```
FRAG
PROPERTY FS_COORD_ORIGIN LOWER_LEFT
PROPERTY FS_COORD_PIXEL_CENTER HALF_INTEGER
DCL IN[0], POSITION, LINEAR
```

Both properties are mandatory and unique before instructions. POSITION must
be the full-mask input0, semantic index0, LINEAR. Other origins, centers,
indices, masks, stages and interpolation modes reject. The builtin highp
gl_FragCoord uses lower-left window half-centers, window depth and interpolated
reciprocal clip W. It is excluded from GENERIC linkage. The v38 wrapper keeps
every underlying v1..v37 numerical and constant-bank obligation, grants no
new range facts and binds its convention into the checked pair selector.
