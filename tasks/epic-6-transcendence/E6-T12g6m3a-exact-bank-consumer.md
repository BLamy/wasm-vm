## Boundary

Add one strict compiler-metadata consumer boundary for exact raw-u32 assumptions on a stage-local slot-zero constant bank. A descending version wrapper retains every inherited bank policy. Validate a canonical bounded sorted unique set of register/component/word constraints against one owned complete declared prefix before shared sync/async draw-triggered linking, index reads, staging, upload or draw effects. Reflection pruning cannot remove an obligation, and absent words cannot be supplied by restore defaults. Copy/approve once; bind that immutable snapshot to current selected shader/program/subcontext generations and reuse existing busy-lock/restore rules.

Every constraint is an exact encoding. Raw count1 is integer1; it supplies no floating result/geometry range. Negative zero differs from positive zero. Reject malformed/missing/accessor/inherited-only/inconsistent policy fields and mismatched words; no asserted guest metadata or observations grant authority. Finite mismatches remain a successfully applied CPU SET prefix, while unsafe restore uploads are skipped and strict DRAW rejects before effects. Normal Inf/NaN wire predecode remains atomic.

This is consumer-only. Physical tests must name their trusted host metadata wrapper over an unchanged real compiler result. No new compiler source admission, original-body specialization, public negotiation, demo import, live offload or performance follows. Producer derivation is a separate ordered S leaf; full E6-T12g6m acceptance remains unchanged.
