## Goal
Execute the RV32M multiplication and division extension exactly for 32-bit operands and results.

## Context
The existing RV64M implementation is useful prior art but cannot be reused by truncating after
RV64 arithmetic: high-half multiplication, signed overflow, and division exceptional cases must
be computed at RV32 widths.

## Deliverables
- RV32 implementations of `MUL`, `MULH`, `MULHSU`, `MULHU`, `DIV`, `DIVU`, `REM`, and `REMU`.
- Directed boundary vectors plus official RV32M signature coverage in native and wasm32 builds.
- A live browser micro-test/roadmap update and `make verify-E3.75-T05`.

## Acceptance criteria
- [ ] `make verify-E3.75-T05` passes the official RV32M signature and the frozen reference trace.
- [ ] Divide-by-zero, `INT32_MIN / -1`, mixed-sign high products, and all-ones operands match the
  RISC-V specification exactly.
- [ ] RV64M results and frozen digests remain unchanged.
- [ ] The browser suite reports the RV32M test `live` with zero console errors.

## Adversarial verification
Cross-product signedness, zero, one, minus one, `INT32_MIN`, `INT32_MAX`, and random operands
against an independent 64-bit mathematical model before truncation. Sabotage one exceptional
case and prove the permanent test catches it; any self-derived oracle or RV64 regression refutes.
