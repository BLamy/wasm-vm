## Goal
Prove the complete scoped Pico 2 machine in one cold, user-visible, deterministic browser run.

## Context
The capstone is not a synthetic register test. A reproducibly built Pico SDK UF2 must traverse
the RP2350 boot handoff and XIP path, use interrupts and both cores, and drive visible serial and
pin behavior through DMA-fed PIO. The same artifact must tell the same story natively and in WASM.

## Deliverables
- `guest/pico2/capstone/` firmware that prints a versioned UART transcript, blinks the Pico 2 LED
  from an alarm IRQ, launches core 1 through SIO, performs an atomic/FIFO exchange, and uses DMA
  to feed PIO for a frozen multi-pin waveform.
- `tools/capstone/pico2.sh`, Playwright automation, digest manifest, screenshot, and guest trace
  evidence from the exact head.
- User documentation for building/loading firmware, controls, supported hardware, and explicit
  exclusions.
- `make verify-E3.75-T30`.

## Acceptance criteria
- [ ] From a pristine clone and fresh browser profile, `make verify-E3.75-T30` builds the page,
  loads the pinned UF2, and reaches every checkpoint with zero console errors or unknown MMIO.
- [ ] UART bytes, core checkpoints, IRQ order, LED transitions, DMA completion, PIO waveform, and
  final state match frozen digests across native and two independent cold browser runs.
- [ ] The existing RV64 browser suite and the full Pico matrix both report their manifest totals
  with zero failures; every scoped Pico capability is `live`/`verified`.
- [ ] Pause/step/reset/reload and one recorded input replay preserve deterministic outcomes and
  leave no leaked worker/listener/object URL.

## Adversarial verification
Use a fresh verifier session and pristine clone. Change scheduling quantum, pause at every named
checkpoint, inject a GPIO event on an alarm/PIO boundary, reset mid-DMA, replay the saved input,
and inspect diff coverage plus evidence digests. Run the high-risk exact-head gauntlet and one
bounded novel attack. Any divergence, unexplained shortcut, unsupported-success MMIO, leaked
resource, or RV64 regression refutes.
