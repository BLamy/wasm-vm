## Goal
Complete the PIO instruction engine's data path: input/output shift registers, thresholds,
auto-push/pull, stalls, and the four shift/FIFO-facing opcodes.

## Context
`IN`, `OUT`, `PUSH`, and `PULL` combine bit ordering, thresholds, side effects, and blocking
behavior. This task uses bounded abstract FIFO ports; MMIO FIFOs, IRQs, and DMA DREQ integration
land in E3.75-T26.

## Deliverables
- Input/output shift registers, shift direction/count, auto-push/pull thresholds, null/exec/PC
  destinations and sources, and deterministic stall tokens.
- Complete `IN`, `OUT`, `PUSH`, and `PULL` behavior against abstract bounded FIFO ports.
- Exhaustive count/threshold vectors, composed timing tests, browser micro-test, and
  `make verify-E3.75-T25b`.

## Acceptance criteria
- [ ] `make verify-E3.75-T25b` matches independent vectors for every source/destination, bit
  count, direction, threshold, blocking mode, and auto mode natively and under wasm32.
- [ ] A stalled instruction repeats no side effect and resumes on exactly the event that makes
  progress possible.
- [ ] Shift-generated pin/exec/PC effects retain the cycle timing established by T25a.
- [ ] The browser panel marks the full PIO instruction set `live` with zero console errors.

## Adversarial verification
Enumerate counts 0/1/31/32, thresholds 0/1/31/32, both directions, empty/full abstract FIFOs,
autopush/pull and manual instructions on the same boundary, and exec-generated stalls. Any
duplicated shift, lost bit, premature PC advance, or one-cycle drift refutes.
