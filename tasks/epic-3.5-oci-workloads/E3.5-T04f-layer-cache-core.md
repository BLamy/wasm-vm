## Goal
The deterministic, storage-agnostic heart of the browser OCI layer cache: content-addressed
put-once/get-forever keyed by sha256 digest, deduped across images, VERIFIED-ON-READ (re-hash on
load; a tampered/corrupt blob is evicted and reported as a miss, never trusted), with LRU eviction of
UNPINNED blobs under a byte budget and a pin/unpin API.

## Context
Split from **E3.5-T04**. The cache LOGIC is pure and node-unit-testable apart from the browser
IndexedDB backing (E3.5-T04g) and the Playwright reload/dedupe/tamper proof (E3.5-T04h). Blobs are
immutable + content-addressed — the easy persistence case (no generations/write-back races).

## Deliverables
- web/oci-blob-cache.js: createLayerCache({blobs, meta, sha256hex, byteBudget, now}) over injected
  async KV stores — has/put/get/pin/unpin/delete/evictToBudget/size/stats, plus sha256HexOf and a
  typed DigestMismatch.

## Acceptance criteria
- [x] make verify-E3.5-T04f (node --test): a round-trip put/get verifies; a put of bytes that don't
  hash to the digest is rejected (nothing stored); a second put of a present digest is a dedup no-op;
  two images sharing a base layer store it once.
- [x] Verified-on-read: bytes tampered in the backing store are evicted + reported as a miss (never
  returned/unpacked); orphan meta (blob gone) is cleaned up.
- [x] LRU eviction removes only the oldest UNPINNED blobs under the byte budget; pinned blobs survive.

## Adversarial verification
Wrong-bytes-under-a-correct-key and a truncated value are both caught on read (digest re-check) and
evicted. A single blob over budget is not silently trusted. Covered by the node suite.
