## Goal
Prove the complete Docker-tab lifecycle composes over the real Alpine guest: boot, guest catalog,
Run, live Containers, Logs, Exec, Stop, and honest degraded behavior, with the anti-fakery contract
checked against the complete source and generated demo.

## Context
The preceding children each verify one boundary. This final slice owns the single slow local-Alpine
Playwright replay and the static/source audit that must hold the whole UI against T05a's honesty rules.
It is the dependency consumed by the E3.5-T05 persistence capstone.

## Deliverables
- One exact-head local Chromium proof of the full lifecycle and guest transcript.
- Static honesty coverage for no canned transcript, fake digest, or JS shell, with guest arithmetic
  markers and no optimistic state shortcuts.
- Rebuilt `web/dist` and a committed screenshot/transcript reference for the verified page.

## Acceptance criteria
- [ ] Fresh local Alpine assets: open Docker → boot → guest-backed Images → Run busybox → running
      Containers → Logs `CONTAINED_42` → Exec `INEXEC_42` → Stop → `exited`, with every value traced
      to guest output and zero unexpected browser errors.
- [ ] The existing Docker static anti-fakery test and a source/dist parity check pass: no JS shell,
      canned transcript, fake digest, or host-literal replacement for `$((6*7))`.
- [ ] Public busybox/no-provider surfaces remain honest in the same focused proof; all Containers
      actions are confirmed by guest `ps`, and the checked-in screenshot/digest matches the exact head.

## Adversarial verification
Kill the container from the Terminal tab, reload Docker, and verify `ps` reflects the external state.
Force Run and Exec failures, re-render Logs during a burst, and cross-check the E3.5-T05a anti-fakery
spec. Run the complete focused command in a fresh Chromium profile; independent machines and WebKit
are not part of this acceptance scope.
