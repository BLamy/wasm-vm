## Goal
Expose a real interactive `wvrun exec -it <id> sh` pane whose input and output remain inside the
selected container, with clean exit and typed absent/exited-container failures.

## Context
T05c proves namespace entry and its honest confinement limits. This slice owns the UI TTY/stream
binding and provenance checks; it must never reuse the Alpine guest shell as a fake exec surface.

## Deliverables
- An embedded or shared-terminal Exec pane driven by `wvrun exec -it` with input passthrough.
- Exit handling that returns to the Containers view and reconciles status from `ps -a`.
- Typed errors for absent/exited targets and visible container provenance (hostname/root/pid namespace).

## Acceptance criteria
- [x] In a real local Alpine run, Exec sends `echo INEXEC_$((6*7))` into the selected container and
      displays guest/container-computed `INEXEC_42` with no host-side shell interpreter.
- [x] The pane proves it is inside the container by showing the container hostname and `/proc/1/comm`
      or root listing, while a guest-only file remains unreadable.
- [x] Exiting returns to the list; exec into an absent or exited container produces a bounded typed
      error and never hangs or opens a bare guest shell.

## Adversarial verification
Attempt `cat /root/guest-secret`, inspect hostname and PID 1, and race Exec with container exit. Verify
the stream cannot attach to the guest shell or a recycled container PID, and no listener survives exit.
