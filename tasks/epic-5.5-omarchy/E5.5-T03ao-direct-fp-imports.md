## Boundary

Replace the five pure browser FP helper Closure imports with direct scalar
exports from the same main WASM instance. Keep the existing helper signatures,
integer-only numerical backends, translator output, precise guards, memory
imports, handoff, cache policy, guest artifacts and scheduling unchanged.
This changes one import boundary within the already measured FP hybrid.

T03an proved FMADD.S but its physical trial still failed all eleven nonce
reads, with no new frame. The exact post-verdict CPU profile places 20.5777%
of weighted samples in the callback subtree and 15.1873% in its generated
closure invocation subtree. These inclusive percentages overlap numerical
work and each other: they do not quantify isolated callback cost or prove the
cause of the input failure. Measure the proposed replacement directly.
