## Boundary

Replace the decoded block cache's page-membership bookkeeping with a page-to-slot
index. A store into a physical page that has no live decoded blocks must remain a
bounded map miss, and a store into a code page must invalidate only the indexed
slots instead of scanning every decoded-cache slot. Preserve the existing physical
page keying, generation flushes, block-discard counters, SMC/DMA invalidation,
executor invalidation, and guest-visible semantics. Do not change JIT admission,
residency, chaining, the decoded-cache capacity, the input recorder, or the product
deadline in this task.

The worker-cost evidence identifies `BlockCache::flush_page` as a 6.6% self-time
sampled region while the physical trials still take tens of seconds to produce a
visible response. This task tests that measured cache-invalidation cost directly;
it is not permission to claim that a microprofile alone solves responsiveness.

The promoted core tests must prove that indexed invalidation drops every live
block on the target page, retains blocks on other pages, handles replacement and
whole-cache generation flushes without stale indices, and leaves the public
invalidation counters unchanged. The frozen browser run must use the exact
prepared cap-1024/recycling/16,384-entry/ICount64 candidate from T03az with the
original 1280×800 geometry, 500,000-instruction quantum, and unchanged
300/60/120/20/30-second budgets. It must record the new WASM identity, the
independent physical nonce, the product screenshot, and the actual returned
terminal prompt. A negative screenshot remains a verified negative experiment.

If the candidate is positive, run `make web-build`, the built-page Playwright
suite with zero console errors and the current live RISC-V count, `make web-dist`,
and the existing Cloudflare Pages deployment path before considering T03q.

## Adversarial verification

A fresh critic compares the changed cache code and the exact T03az runtime
settings, predicts that a non-code-page store performs no slot walk, and predicts
that a code-page store removes only the indexed target slots. It must exercise a
same-page replacement, an invalidation followed by reinsertion, a stale
generation flush, and a forged page index entry or missing index entry. It must
reject any implementation that silently falls back to a full-capacity scan, drops
blocks from another page, changes `blocks_discarded`, or calls the physical trial
successful from a frame count alone. The verifier must inspect the real PNG and
keep T03q gated unless the returned prompt is visible inside the original product
window.
