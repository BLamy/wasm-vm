## Boundary

Evaluate clock-accounting candidates against current main `0a5f7bd7`, with
identical guest programs, host retirement budgets and guest-clock policy. Keep
a candidate only if its divider-64 browser cached-interpreter median improves
with no state difference. Reject a neutral or slower candidate. The delivered
boundary is the measurement harness and independent clock regression fixtures;
rejected runtime changes must be absent from the final diff and production WASM.

The initial checkout was behind the September performance overhaul. Main already
removed common u128 division and specialized single retirements. Earlier
measurements against `82978509` prove no improvement over current main.

## Deterministic acceptance

`make verify-E5.5-T03bd`

- Independent u128 oracles cover dividers, restored phases, spans, overflow,
  mtime wrap, wall mode and missing CLINT. Native and wasm guest rdtime fixtures
  cover split budgets and byte-exact resume, with guest trace/state digests.
- Use one public-API producer for both native libraries, explicit matching fat
  LTO flags and preserved crate filenames. Use the current production browser
  module as the baseline; its rebuild must reproduce the pinned bytes.
- Retain five alternating pairs per native/browser configuration, actual
  compiled execution, exact retirement/clock oracles and full state receipts.
  Record rejected candidates honestly. Identical browser bytes are a control,
  and timing noise in that control must never become a speedup claim.
- Final runtime source matches current main except a cfg(test) module. Final
  WASM equals baseline bytes. Record a final unchanged-runtime control,
  affected native/wasm fixtures, built-demo suite, and clean-environment clone
  checks for the harness. Preserve pre-existing gauntlet failures.
- Update the demo evidence to state the negative outcome; do not claim faster
  desktop execution or alter its artifacts, JIT defaults or response deadline.

## Adversarial verification

A fresh critic predicts concrete tick/phase values before checking fixtures,
independently recounts paired timing/state receipts and verifies the final
runtime diff and WASM identity. Attack overflow, the largest divider, restored
phase, mtime wrap and no-op modes. Invent one bounded attack on the measurement
harness, and confirm an identical-binary control cannot be called an optimization.
Promote the useful tests/trace; no rejected code is implementation evidence.
