  attributing improvement or publishing, repeat matched clean LP1/LP0 arms
  with startup DEBUG logging identically enabled, capture each measured
  compositor's strict GL labels, then identically disable logging before
  timing physical input. An auxiliary EGL client cannot identify the
  compositor's active renderer.
- A fresh critic audits the scoped measurement before this prerequisite
  can become verified. A verified negative diagnostic is not a desktop fix.
