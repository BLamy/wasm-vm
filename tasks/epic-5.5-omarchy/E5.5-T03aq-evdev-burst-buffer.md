## Boundary

Build an isolated Linux6.6.63 Omarchy kernel variant whose sole runtime change
raises EVDEV_MIN_BUFFER_SIZE from64 to1024 events. Each evdev client gains
23040 bytes of bounded queue capacity. Preserve the existing baseline kernel,
config, toolchain identity and AO emulator/WASM bytes. No queue, deadline, guest
service, rendering or resolution changes in the emulator. Risk is medium: this
changes fixed guest input buffering capacity without changing the ring algorithm,
locking, architecture or snapshot format.

AP observed real compositor input synchronization loss. Overflow is a supported
hypothesis, not uniquely proven by SYN_DROPPED. Test actual Linux behavior before
creating a new desktop pair; old RAM snapshots still contain the old kernel.
