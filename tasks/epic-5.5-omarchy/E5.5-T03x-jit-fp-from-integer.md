## Boundary

Compile FCVT.S.W/WU/L/LU through one pure call to the existing integer-only
`softfloat::f32_from_int` backend. Pass the integer source, width/signedness
and resolved rounding mode; return packed raw result bits and flags through
the existing verified FPR/FP-control handoff. Reuse the precise FS/rounding
guards established for arithmetic. Other conversion directions and arithmetic
families stay interpreted. No new arithmetic implementation or Epic 6 work.

T03s measured 985,870 from-integer conversion retirements in 99,998,678
instructions. The saved renderer page contains 18 dynamic-rounding instances
alongside the now-supported moves, memory, comparisons and arithmetic. T03w's
actual desktop trial still produced no nonce or typed response at 120 seconds.
These conversions remain unsupported by whole-block admission. Start only
after independent T03w verification.
