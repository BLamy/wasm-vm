## Acceptance criteria

- Prepare a separately named candidate from the exact verified SDR base. Change
  only the equal-length `GALLIUM_DRIVER=llvmpipe` configuration values to
  `GALLIUM_DRIVER=softpipe` in the two declared environment files. Record image
  hashes, exact changed byte ranges, and unchanged ownership/mode metadata.
- A fresh real-emulator run must bind the candidate to its actual image,
  kernel, core and base-manifest identities. Native capture may produce a
  paired RAM/disk artifact. Alternatively, a fresh target-WASM cold boot
  without a snapshot, delta, persistence or reused worker can establish
  renderer compatibility directly. Record the actual renderer process
  environment and startup result; a concrete initialization failure is a
  negative compatibility result, not an input-performance result. A timeout
  or missing renderer evidence is unproven. The target-WASM cold-start budget
  is 90 minutes, separate from the unchanged 120-second input criterion.
- If it starts, run the actual built browser with that pair and take screenshots
  before/after physical input. Retain the existing independent nonce readback
  and 120-second limit. Record failure honestly; this measurement task does not
  itself claim a usable desktop or permit publishing an unverified candidate.
- A fresh critic audits image identity, measurement validity, and any conclusion
  before this prerequisite is marked verified.
