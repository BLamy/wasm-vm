## Boundary

Compile FDIV.S through a pure packed-result helper backed by the existing
integer-only `F32::div` implementation. Reuse precise FS/rm checks, source
NaN-box canonicalization and boxed result/flag publication. Keep this helper's
allocated optional import index alongside arithmetic and both conversion
directions. Other arithmetic families and double precision remain unchanged.
No host floating-point operations, guest scheduler changes or Epic 6 expansion.

T03s measured 213,132 FDIV.S retirements in 99,998,678 instructions. A static
scan of the saved renderer page identifies four dynamic-rounding FDIV.S
encodings. Division still excludes their whole blocks from JIT admission.
T03y's physical trial accepted 128 trusted events but again failed nonce
readback at 120 seconds, with frames 2→2 and an unchanged terminal. Start only
after T03y is independently verified. This measurement justifies testing the
remaining division boundary; it does not predict a usability success.
