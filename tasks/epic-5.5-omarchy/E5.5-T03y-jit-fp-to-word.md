## Boundary

Compile FCVT.W.S and FCVT.WU.S through the existing integer-only
`softfloat::f32_to_int` backend. A pure helper returns the low 32 result bits
and new flags in the existing packed u64 convention. Generated code sign-extends
the word result into an integer destination, including the architectural
sign-extension rule for WU, and accrues flags/FS state without changing any FPR.
Reuse precise FS/rm checks and source NaN-box handling. L/LU destinations,
double precision and remaining arithmetic keep their established paths.

T03s measured 426,264 retirements in the single-precision float-to-integer
family. That aggregate does not distinguish integer destination widths. A
static scan of the saved renderer page identifies eight FCVT.W.S instructions,
all with RTZ, among the previously measured FP operations. These still exclude
their whole blocks from JIT admission. W/WU share the one 32-bit result boundary;
this task does not introduce a 64-bit result/flags ABI. No Epic 6 work.

T03x's actual desktop trial again failed at the original 120-second deadline,
with no independently read nonce or typed terminal response. Start only after
T03x is independently verified.
