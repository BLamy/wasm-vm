## Boundary

AS proves physical command execution with the AQ kernel but the actual terminal
image remains stale even after a post-nonce frame. The local Linux6.6.63 driver
virtgpu_plane.c:122–130 already computes source offset=x*cpp+y*pitch before
sending TRANSFER_TO_HOST_2D. resources.rs currently adds rect.x/rect.y again.
QEMU9.2.0 virtio-gpu.c:430–443 reads source offset plus row stride and uses the
rectangle origin only for the destination. Correct this one transfer boundary;
do not change scanout selection, render resolution, guest settings or JIT policy.
