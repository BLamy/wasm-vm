## Boundary

Connect FADD.S and FMUL.S in generated blocks to the existing integer-only
SoftFloat backend through one pure arithmetic helper. Pass raw operand bits
and the resolved rounding mode, return raw single-precision result bits and
accrued flags, then publish them through the verified FPR/FP-control handoff.
The current backend remains the arithmetic authority; this slice removes the
whole-block interpreter boundary for these two measured operations.

Pre-freeze independent literal expectations exposed an inherited backend flag
gap: finite-saturating F32 addition/multiplication overflow reports only NX.
Correct this status mapping in the shared backend for these two operations;
retain its rounded result and use its widened integer-only operation solely
to distinguish true overflow from near-boundary inexact saturation. Other FP
families and formats stay unchanged. Include literal overflow/non-overflow
threshold tests and carry this hunk through the same high-risk verification.

The verified T03s recording contains 1,709,360 FADD.S and 2,561,888 FMUL.S
retirements in 99,998,678 instructions. The saved live renderer page also
contains repeated dynamic-rounding FADD.S/FMUL.S next to the already supported
moves, transfers and comparisons. T03v's physical trial at frozen source
`2e7cd66994e63c1ca39f492d49c5764a31c87739` again failed the unchanged
120-second readback deadline, with 128 trusted accepted events and frames2→2.
This task stays pending until T03v is independently verified.
