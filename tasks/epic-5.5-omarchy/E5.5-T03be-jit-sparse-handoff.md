## Boundary

Following the user's October 1 request to continue speed optimization, measure
and optimize the integer dirty-mask commit at browser JIT exits. The current
implementation visits all 31 writable registers even for an empty or sparse
mask. Measure empty/full fast paths, sparse bit iteration and a dense scan,
preserving x0, unselected words, PC and the exact mutation-stamp update. Keep the public ABI, generated code, chaining
policy, guest clocks and snapshots unchanged. Native full-register commits are
outside this boundary. If no candidate meets the unchanged performance gate,
restore production code and artifacts; retain the tests and measured negative
result. A verified investigation does not imply an emulator speedup.
