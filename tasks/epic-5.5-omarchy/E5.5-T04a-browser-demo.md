## Boundary

The demo entrypoint, immutable Omarchy boot manifest, and existing browser
display/input integration. Default to the verified clean Omarchy image without
silently falling back to an older guest or old writable state. Preserve the
machine's capability suite, but remove legacy default-boot selection behavior.
Publishing the release is the following task.

## Acceptance criteria

- A fresh Chromium context opens the actual built demo and starts the exact
  verified Omarchy image with its matching kernel. Kernel and chunk integrity
  remain enforced; no earlier guest snapshot or overlay is imported.
- The existing display presents the real Omarchy shell and a mapped Foot
  terminal. Physical keyboard input reaches that terminal and produces an
  independently checked result. Serial diagnostics remain available.
- Boot errors remain visible and do not trigger a legacy-guest fallback.
- The capability suite passes with zero non-favicon browser console errors;
  the roadmap accurately labels the demonstrated Omarchy capability.
