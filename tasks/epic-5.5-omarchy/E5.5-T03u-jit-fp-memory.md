## Boundary

Translate FLW/FSW and FLD/FSD, including the existing RV64 compressed FLD/FSD
expansions, through the same checked memory path as integer loads/stores. This
is one memory-transfer boundary, using T03t's FPR handoff and precise FS trap.
It introduces no floating-point arithmetic or comparison implementation.

The current renderer profile reports 4,241,032 FP memory transfers in its
99,998,678-retirement window, and the independently inspected live renderer page
contains FLW/FSW beside FSGNJ.S and FLE.S. T03t's physical-input retry failed at
the unchanged 120-second deadline with no fresh frame; instruction support is
insufficient. Remove the next measured interpreter boundary, then retest input.

## Deterministic acceptance

`make verify-E5_5-T03u`

- Real native and browser generated modules transfer the exact raw low 32/64
  bits through RAM, preserving NaN payloads. FLW boxes its result; stores never
  canonicalize malformed boxes. f0 is writable; integer/FPR index aliases stay
  separate. A successful load dirties FS; stores preserve FS. All four
  instructions and their compressed expansions keep fflags/frm unchanged.
- FS=Off traps before any memory access, even for unmapped/MMIO addresses;
  compressed instructions report their original 16-bit mtval. Successful and
  faulting loads/stores retain the interpreter's access/page/misalignment/PMP
  behavior, exact virtual PC and retirement prefix, with no replayed side effect.
- Cover private imported memory and actual shared-memory inline hits/misses,
  noncontiguous virtual pages, RAM/MMIO stores, code-write/reservation barriers,
  and same-/cross-module successors. Reuse existing memory authority checks;
  do not add a permissive FP-specific memory import.
- The high-risk submission records affected tests, the prescribed local gauntlet
  with any unchanged platform limitations identified, built-page compiled FP
  memory proof plus the full live ISA suite, exact source/artifact/guest-state
  digests and one final pristine-clone acceptance. Commit web/dist and deploy
  the validated capability through Cloudflare; no Actions or merges.
- Run the actual Omarchy physical-keyboard nonce trial at 120 seconds and inspect
  its real application screenshot. Keep T03q gated on failure; neither a new
  frame alone nor opcode correctness is a responsive-desktop verdict.
