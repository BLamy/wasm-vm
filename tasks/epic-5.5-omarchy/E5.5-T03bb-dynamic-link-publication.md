## Boundary

When generated dynamic JALR chaining is disabled, stop publishing resolved JALR
targets into the browser dynamic-link cache. The current cap-1024 / decoded-16384
trial reports `jitDynamicChaining: false` and zero generated dynamic probes, while
still recording 14.6 million `dynamicLinkInstalls`; those publications perform
map, authority, and table work that the disabled generated path cannot consume.
Keep static region chaining, compiled execution, virtual-to-physical checks,
ordinary dispatch, and all guest-visible behavior unchanged. If the option is
enabled, preserve the existing publication and guarded-hit behavior. This slice
does not change the JALR option, cache capacity, residency policy, input path,
renderer, or release deadline.

## Deterministic acceptance

- Add a focused core or browser-executor regression proving that a compiled
  dynamic successor is not published while dynamic chaining is disabled, and is
  published when it is enabled.
- Run the affected native/core tests, browser JIT parity tests, strict clippy,
  formatting, and the wasm target check.
- Run the existing focused Omarchy harness suite and a fresh physical trial with
  the unchanged cap-1024, recycling, decoded-16384, JALR-off settings. The run
  must bind the exact candidate WASM and report both `dynamicLinkInstalls` and
  architectural/runtime acceptance.
- A responsiveness pass requires the independent physical nonce and visible
  typed application response before the unchanged 120-second deadline. If it
  remains stale, retain the negative product result and replan from the measured
  counters.

## Adversarial verification

A fresh critic compares dynamic-on and dynamic-off publication counts, verifies
that a later dynamic-on toggle still publishes and hits safely, and runs one
bounded virtual-to-physical remap or authority-change case. It checks that static
edges still chain, dynamic-off execution remains guest-equivalent to the
interpreter, and no disabled-path map/table mutation is hidden behind a counter.
The critic independently reconstructs the physical nonce/readback and inspects
the actual response image; counters alone cannot open T03q.
