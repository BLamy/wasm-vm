## Boundary

One isolated local trial on the unchanged R3 snapshot, image and production WASM.
T03p showed that changing the advertised display mode did not make Hyprland adopt
it. After that same single 640×400 display request, issue one fixed ephemeral
`hyprctl eval` monitor configuration command. No image/config-file writes,
compositor restart, timing change or renderer/JIT change. This is a bounded
measurement; a complete negative receipt is not a responsiveness fix.
