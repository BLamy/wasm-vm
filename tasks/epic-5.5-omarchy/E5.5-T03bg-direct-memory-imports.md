## Boundary

The October 2 user request targets approximately 300 browser MIPS and explains
that v86/WebVM feel more responsive. Existing compiled arithmetic already reaches
640–648 MIPS; real mixed work is slower. Remove JavaScript/BigInt marshalling from
the five browser JIT memory imports by binding raw scalar wasm exports to the
existing load/store/AMO/LR/SC helpers. Preserve all address translation, permission,
trap, invalidation, reservation, device and chain-abort behavior. Guard calls made
without an active host context before dereferencing any pointer. This task changes
one import boundary; it does not promise 300 MIPS for desktop workloads.
