# Required color storage recording

`worker/manifest.json` binds the frozen G2 source head, `records.json` member
index and deterministic `recording.tar.gz`. Check the archive/member hashes
before using the recording. Every member is a relative regular file; unpack
only after checking its name, size and SHA256 against the index.

The archive contains the complete affected local gate, final scrubbed pristine
clone, original packet/backing source bindings, hardware screenshots, V8 counters,
physical channel/alpha/precision assertions, two rejected source faults and the
exact generated WASM translator used by the browser. Original selected inputs
remain authenticated by G1's immutable kmscube and original es2gears inventories.
Reference-rendered images are never upload inputs.

This is isolated required color storage evidence. New shader/body closure,
depth, sampler-view specialization, inline writes, scanout conversion and live
guest negotiation are subsequent boundaries. No performance gain is claimed.
